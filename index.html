MJSNet package repositories

dnf (RHEL, AlmaLinux, Rocky, Fedora)

  • MJSNet 1.2.3 (el10, 64-bit ARM)
  • MJSNet 1.2.3 (el10, 64-bit Intel/AMD)

Add the repository once, then MJSNet updates with the rest of the system:

sudo rpm --import https://msanty573.github.io/MJSNet-Downloads/RPM-GPG-KEY-mjsnet
sudo curl -o /etc/yum.repos.d/mjsnet.repo https://msanty573.github.io/MJSNet-Downloads/mjsnet.repo
sudo dnf install mjsnet

apt (Ubuntu 26.04 and newer)

  • MJSNet 1.2.3 (64-bit Intel/AMD)
  • MJSNet 1.2.3 (64-bit ARM)

Installing the package also adds this repository, so MJSNet then updates with the rest of the system:

wget https://github.com/msanty573/MJSNet-Downloads/releases/download/latest/mjsnet.ubuntu.$(dpkg --print-architecture).deb
sudo apt install ./mjsnet.ubuntu.*.deb
